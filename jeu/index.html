Comment jouer

But : détruire le centre-ville 🏰 adverse.

Sélectionner : tape/clique une unité, ou fais un glisser (souris) pour une sélection multiple. Double-tap sélectionne toutes les unités du même type à l'écran.

Donner un ordre : avec des unités sélectionnées, tape/clic-droit sur : le sol (se déplacer), un arbre 🌲 / des baies 🍒 / de l'or 💰 (récolter, villageois), un ennemi (attaquer).

Construire : sélectionne un villageois → bouton de bâtiment → place-le sur la carte.

Former des unités : sélectionne le centre-ville (villageois) ou la caserne (soldats/archers) → bouton d'unité.

Caméra : glisse à deux doigts (mobile) ou molette pour zoomer ; utilise la mini-carte pour te déplacer vite.

Population : construis des maisons 🏠 pour augmenter ta limite.
