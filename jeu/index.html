Comment jouer

But : détruire le centre-ville 🏰 adverse.

Sélectionner : tape/clique une unité, glisse (souris) pour une sélection multiple, double-tap pour toutes les unités du même type visibles.

Ordres : unités sélectionnées → tape/clic droit sur le sol (aller), une ressource (récolter, villageois), un ennemi (attaquer). Les unités contournent les obstacles.

Contres : 🛡️ lancier bat 🐎 cavalier • 🐎 cavalier bat 🏹 archer • 🏹 archer bat l'infanterie. Compose ton armée en conséquence.

Économie : construis moulin / camp de bûcherons / camp minier près des ressources pour raccourcir les trajets. 🏠 maison = population.

Âges : au centre-ville, fais évoluer ton âge (I→IV) pour débloquer unités, bâtiments et améliorations.

Caméra : glisse à deux doigts / molette (zoom), mini-carte pour te déplacer.
