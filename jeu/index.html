Comment jouer

But : détruire le centre-ville 🏰 adverse.

Sélectionner : tape/clique une unité, glisse (souris) pour une sélection multiple, double-tap pour toutes les unités du même type visibles.

Ordres : unités sélectionnées → tape/clic droit sur le sol (aller), une ressource (récolter, villageois), un ennemi (attaquer). Les unités contournent les obstacles.

Contres : 🛡️ lancier bat 🐎 cavalier • 🐎 cavalier bat 🏹 archer • 🏹 archer bat l'infanterie.

Caméra : glisse à un doigt (mobile) ou molette pour zoomer ; deux doigts pour pivoter/zoomer ; flèches et Q/E au clavier. Mini-carte pour te déplacer.

Économie : moulin / camp de bûcherons / camp minier près des ressources raccourcissent les trajets. 🏠 maison = population. Fais évoluer ton âge au centre-ville.
